# drbartel.com

Persönliche Website von Dr. Holger Bartel, statisches HTML/CSS, ausgeliefert über GitHub Pages.

- Keine Cookies, kein Tracking, keine externen Schriften, Skripte oder CDNs.
- Deutsch/Englisch: Vorwahl nach Browsersprache, sonst Englisch; die Wahl über die Flaggen wird nur im
  Browser gespeichert (`localStorage`, Eintrag `lang`). Ohne JavaScript erscheint Englisch.
- Seiten: `index.html`, `impressum.html`, `datenschutz.html`; Gestaltung `assets/style.css`, Sprachwahl `assets/lang.js`.
- Neu aufgebaut im November 2026; die alte WordPress-Seite wird nicht weiterverwendet.
